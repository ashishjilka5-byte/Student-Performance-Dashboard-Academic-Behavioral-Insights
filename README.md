# 🎓 Student Performance Dashboard: Academic & Behavioral Insights

## 📌 Project Overview

This project is an interactive **Power BI dashboard** designed to analyze student performance based on academic scores, attendance, and behavior. It provides actionable insights to help educators and stakeholders make data-driven decisions.

---

## 📊 Key Features

* 📈 Academic performance analysis by subject and class
* 📉 Trend analysis across terms
* 🧠 Behavioral insights using distribution charts
* 📅 Attendance tracking and impact on performance
* 🎯 KPI cards for quick overview

---

## ⚙️ Tools & Technologies Used

* Microsoft Power BI
* DAX (Data Analysis Expressions)
* Data Modeling & Relationships
* Power Query (Data Cleaning)

---

## 🧮 DAX Measures Implemented

* % Score
* Average Score
* Attendance %
* Behavior Count
* Performance Category (High / Medium / Low)

---

## 📊 Visualizations Used

* Bar Chart → Average Score by Subject & Class
* Line Chart → Performance Trend by Term
* Donut Chart → Behavior Distribution
* Table → Student-wise scores with conditional formatting
* Cards → Total Students, Avg Score, Attendance %

---

## 🎛️ Interactivity Features

* Slicers (Class, Section, Subject, Term)
* Drillthrough (Student Detail Page)
* Custom Tooltips (Hover insights)
* Bookmark Navigation (Switch views)

---

## 🔍 Key Insights

* Students with higher attendance generally perform better
* Some subjects show lower average scores, indicating improvement areas
* Behavioral patterns influence academic outcomes
* Consistent students achieve higher performance

---
